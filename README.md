src/testDataCollection_initial_value.ipynb

There are two ways to run the project.

Option 1 — Run the Full Notebook

Run all cells from the beginning.

This will execute the complete pipeline, including:

data collection,
data analysis and preprocessing,
construction of the final datasets,
model training,
model evaluation.

This option should be used when running the project for the first time or when the raw data need to be refreshed.

Option 2 — Run from Step 10

If the data have already been collected and saved locally, you can skip the data collection and exploratory analysis steps.

Start from:

Step 10 — Construction of the final DataFrames

and run all subsequent cells.

This option is faster and is recommended when you only want to reproduce the modelling and evaluation results without downloading the raw data again.
